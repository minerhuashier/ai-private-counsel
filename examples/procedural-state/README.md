# 程序状态登记示例

本目录只提供脱敏模板，不接收真实案件材料。

## 文件

- [程序状态登记模板](state-register.template.md)：按案件身份、程序类型、费用、送达、期限、证据、审理、文书与批准八条状态轴登记来源、时间、证明范围和下一步行动。

## 使用规则

1. 只使用占位符、虚构日期、虚构编号和虚构金额；
2. 保留每个来源的原文、抓取时间和证明范围；
3. 来源冲突时标记 `conflict`，不要强行合并；
4. 没有本人明确批准时，批准字段写 `none`；
5. 真实案号、法院文书、银行回单、证据和个人信息留在私有工作区。

本模板是信息整理工具，不构成法律意见，也不替代传票、正式通知、法院平台或法院工作人员答复。

# Procedural State Register Examples

This directory contains de-identified templates only. It does not accept real case materials.

## Files

- [Procedural-state register template](state-register.template.md): records the source, time, proven scope, and next action for eight state axes: case identity, procedure type, fees, service, deadlines, evidence, hearing, and documents/approval.

## Rules

1. Use placeholders, fictional dates, fictional identifiers, and fictional amounts only;
2. Preserve the source text, capture time, and proven scope;
3. Mark a source conflict as `conflict`; do not force the records into one conclusion;
4. Write `none` in the approval field when no explicit human approval exists;
5. Keep real case numbers, court documents, bank receipts, evidence, and personal information in a private workspace.

This template is an information-organization tool. It is not legal advice and does not replace a summons, formal notice, court platform, or answer from court staff.
