# 决策路径记录

本目录提供完全去标识化的模板，用于记录一项维权问题如何从模糊诉求，经过证据、法律关系、责任主体、管辖、法律依据和文书审计，最终形成可由本人决定是否执行的下一步。

模板不接收真实姓名、平台主体、商家、法院、案号、金额、订单号、联系方式、证据原文或法院文书。

# Decision-Path Records

This directory provides fully de-identified templates for recording how a claim moves from an unclear objective through evidence, legal relationship, responsible party, jurisdiction, legal authority, and document audit to a next step that the human may decide to execute.

The templates must not contain real names, platform entities, merchants, courts, case numbers, amounts, order identifiers, contact information, source evidence, or court documents.
